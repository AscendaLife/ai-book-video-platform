# 书影 BookReel · AI 新书短视频内容生产平台（演示原型）

> 一本书 · 一座内容库

一本书上传进来，自动变成几十支可发布的多平台短视频。

**在线预览**：打开本仓库的 GitHub Pages 地址即可，无需安装任何东西。

## 三分钟看完
1. 左侧点「生产流水线」，右上角点「一键跑完整流程」
2. 约 15 秒看完七个步骤：上传资料 → AI 读完整本书 → 批量写稿 → 套用人格 → 数字人合成 → 自动包装 → 多平台输出
3. 去「内容资产库」看产出的 30 支视频、14 篇脚本、20 个标题、20 个 Hook
4. 去「数据分析」看播放趋势与转化漏斗

## 单独功能：书影（书中人物）

侧边栏最下面「单独功能 · 书影（书中人物）」是一条**跟流水线无关**的路径，随时进去就能用，不必先跑完前面几步。

它做的事：把书里的**男主角、女主角与其他主要人物**，一个一个变成数字人，让他自己对着镜头讲一段自我介绍。

自述稿按「影片实际念出来的顺序」分成四块，共 14 段，每段都可以自己改，留空的不会念到：

| 块 | 段落 |
| --- | --- |
| 开场 · 前三秒 | 一句话钩子 |
| 他是谁、他在哪里 | 我是谁 / 这本书的情景 / 我周遭的环境 / 我现在的行为 |
| 他心里的事 | 我的心态 / 我怎么走到这一步 / 我卡在哪里 / 我身边的人 / 我的想法 / 我后来明白了什么 |
| 收尾 | 我接下来要做什么 / 我最想说的一句话 / 给看到这里的你 |

只讲「此刻在做什么、心里怎么想」的自述会很平，所以补上**前史**与**卡在哪里**撑张力；**我身边的人**让同一本书的
几个人物互相提到对方，几支影片才像同一个故事；**我后来明白了什么**把这本书的观点落在人身上；**最后一句**把人带回这本书。

另外两个不会被念出来、但写稿前要先决定的设定：**影片长度**（30 / 60 / 90 秒，决定 AI 写多少字，也就决定这支影片多贵）
与**念的口吻**（男主角跟女主角不该同一个语气）。

三步：
1. 让 AI 从书里读出主要人物（几乎不花钱）
2. 生成定妆照（这就是影片里那张脸，约 US$0.03-0.07 一张）＋ 写自述稿
3. 生成自述短片（一支约 US$1-3，跟流水线共用同一个月额度）

人物名单与「创意分镜 · 书中角色」共用同一份资料，在任一边读出来的人物，另一边直接看得到。
